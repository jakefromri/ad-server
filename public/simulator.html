Where do I get a tenant API key?
The API base URL defaults to wherever this page itself is hosted, so dev and prod each talk to their own environment automatically — no manual switching. Grab a key from GET /v1/tenant/api-key or the tenant dashboard's API settings page. On dev, the seeded "Tenant 0" test tenant's key is in simulator/.output/tenant0-credentials.json. On prod, use a dedicated test tenant — never a real customer tenant's key. This tool talks directly to whatever API base URL and tenant key you give it — nothing is hardcoded server-side, and the field is editable if you want to point it somewhere else.
